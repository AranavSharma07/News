# Google AdSense setup

The global AdSense loader is included in `app/layout.tsx` for publisher ID `ca-pub-7274245941888092`.

- This loads the AdSense script site-wide.
- It does not guarantee ads will appear; Google account/site approval and AdSense configuration are still required.
- After deployment, confirm the live site is accessible and check AdSense for any site review or policy messages.
- Do not add a second copy of this loader elsewhere in the app.
