# NaukriSetu — Jobs, Admit Cards, Results & Education Updates

A responsive static website starter for an Indian job and education update portal.

## Included features
- Search across sample job/exam/update listings
- Category filters for Jobs, Admit Cards, Results, Answer Keys, Admissions and News
- Save/bookmark cards with browser localStorage
- Dark mode
- Hindi/English hero text toggle
- Job alert preference form (local-only demo, no email delivery)
- Age calculator, deadline planner, application checklist, eligibility notes and study plan tools
- Responsive mobile layout, accessible dialog, privacy note and disclaimer
- SEO title and meta description

## Important before publishing
The included cards are **illustrative demo entries**, not verified current vacancies or official announcements. Replace them with sourced, accurate updates and official links. Do not imply a job/result/admit card is real unless verified.

## Deploy on Vercel
1. Extract the ZIP.
2. Upload `index.html` to a GitHub repository.
3. Import the repository into Vercel. This is a static site; no build command is required.
4. Add your domain and update the privacy policy, contact details, editorial process and official source links.

## Production features that need a backend
Live news ingestion, admin dashboard, CMS, email/push notifications, user accounts, analytics and persistent database are not connected in this starter. Alert preferences are stored only in the visitor's browser. Connect a secure backend and a verified content source before offering those as live services.
